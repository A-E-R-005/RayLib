This is slightly trickier because you need to account for the size of the player. If the player's top-left corner (playerPosition.x) reaches GetScreenWidth(), the player will alerafy be completely off the screen.

- Right Limit: ScreenWidth - PlayerWidth
- Bottom Limit: ScreenHeight - PlayerHeight

```
// Check Right Boundary (X-axis)
float rightLimit = (float)GetScreenWidth() - playerWidth; // Use float for math
if (playerPosition.x > rightLimit) {
    playerPosition.x = rightLimit;
}
```
