The cleanest and most common way to handle movement is by accumulating all movement inputs into a single Direction Vector, and then applying that vector (multiplied by speed) to the player's position.

This is more extensible and prepares you for using Delta Time later (Lesson 5)

1. Define The Direction Vector
		Instead of directly changing the `playerPosition`, you first define a separate Vector2 called `playerDirection` (or `movementDelta`)

```
// 1. Define a vector to store the direction of movement for the current frame
Vector2 playerDirection = {0.0f, 0.0f};
```


2. Accumulate Inputs
		In the Update section, check for all inputs independently and add to the `playerDirection` vector. 
		Since this uses a sequence of independent `
		```if``` statements, you can press W and D simultaneously, and the vector will become ```{1.0f, -1.0f}```. 

```
// Update Phase: Accumulate inputs into the direction vector
if (IsKeyDown(KEY_W)) {
    playerDirection.y -= 1.0f; // Moving up (Y decreases)
}
if (IsKeyDown(KEY_S)) {
    playerDirection.y += 1.0f; // Moving down (Y increases)
}
if (IsKeyDown(KEY_A)) {
    playerDirection.x -= 1.0f; // Moving left (X decreases)
}
if (IsKeyDown(KEY_D)) {
    playerDirection.x += 1.0f; // Moving right (X increases)
}
```
