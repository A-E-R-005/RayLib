In lesson 1, I defined the screen size with variables (screenWidth, screenHeight), but raylib also has handy functions to get these values at any time

GetScreenWidth(void)
GetScreenHeight(void)

| **Function**      | **Signature** | **Explanation**                                            |
| ----------------- | ------------- | ---------------------------------------------------------- |
| `GetScreenWidth`  | `(void)`      | Returns the current width of the game window as an `int`.  |
| `GetScreenHeight` | `(void)`      | Returns the current height of the game window as an `int`. |
