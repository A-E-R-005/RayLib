These are the functions that implement the four stages:

	InitWindow(int width, int height, const char *title)
Creates and opens the main window and initializes the OpenGL Context. Must be the first rayLib function called


	SetTargetFPS(int fps)
Tells the program to aim for a maximum frame rate (e.g., 60 FPS). This keeps game speed consistent

	CloseWindow(void)
Closes the window, unloads the OpenGL Context, and cleans up memory. Must be the last rayLib function called.
