The main logic in a rayLib program is divided into four stages that run continuously:

1. Initialization -(Before the Loop)
		Set up variables, load assets (textures, sounds), and create the window
2. Update (Inside the Loop)
		Game Logic: Handle input, calculate movement, check collisions, and update scores
3. Draw (Inside the loop)
		Rendering: Clear the screen and draw all game elements (shapes, text, images)
4. De-initialization (After the loop)
		Clean up resources, close files, and close the window safely
