To draw anything in RayLib you need three things: what to draw (the function), where to draw it (coordinates), and what colour it should be.

1. Coordinates and Positioning:
	RayLib uses a standard 2D coordinates system:
		- The origin (0, 0) is the top-left corner of the window
		- The x-axis increases as you move right
		- The Y-axis increases as you move down (this is the key difference form typical math graphs

2. Colours in RayLib
	Raylib uses a built-in colur structure based on the Red-Green-Blue-Alpha (RGBA) model.
		- Built-in colours: Raylib provides many predefined colours (e.g., RED, BLUE, RAYWHITE, GOLD).
			- DrawRectangle(..., RED);
		- Custom colours: you can create any colour using the function:
			- Color myCustomColor = {R, G, B, A}
			- where R,G,B,A are the values from 0 to 255

|**Function/Type**|**Description**|**Example**|
|---|---|---|
|`Color` structure|Holds the R, G, B, A values.|`Color custom_yellow = {255, 255, 0, 255};`|
|`RED`, `BLUE`, etc.|Predefined `Color` constants.|`DrawRectangle(..., RED);`|


3. Basic Drawing Functions:
	All drawing functions must be called between BeginDrawing() and EndDrawing()
		DrawPixel(int posX, int posY, Color colour)
			- Draws a single coloured pixel
		DrawLine(int startX, int startY, int endX, int endY, Color colour)
			- Draws a line segment between two points
		DrawCircle(int centerX, int centerY, float radius, Color colour)
			- Draws a solid circle
		DrawRectangle(int posX, int posY, int width, int height, Color colour)
			- Draws a solid rectangle. posX and posY are the top-left corner
		DrawText(const char text, int posX, int posY, int fontSize, Color colour)
			- Draws text onto the screen

|**Function**|**Signature**|**Explanation**|
|---|---|---|
|`DrawPixel`|`(int posX, int posY, Color color)`|Draws a single colored pixel.|
|`DrawLine`|`(int startX, int startY, int endX, int endY, Color color)`|Draws a line segment between two points.|
|`DrawCircle`|`(int centerX, int centerY, float radius, Color color)`|Draws a solid circle.|
|`DrawRectangle`|`(int posX, int posY, int width, int height, Color color)`|Draws a solid rectangle. `posX` and `posY` are the top-left corner.|
|`DrawText`|`(const char *text, int posX, int posY, int fontSize, Color color)`|Draws text onto the screen.|
