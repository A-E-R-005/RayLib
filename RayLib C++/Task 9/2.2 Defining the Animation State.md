We need a dedicated variable in the `Player` structure to track whether the player is currently active or stationary.

`player.h` (Add State Definition)
	Define the `enum` and the `currentState` variable within your `Player` structure.

```c++
#ifndef PLAYER_H
#define PLAYER_H
#include "raylib.h"

// 1. Define the possible states
enum PlayerState { IDLE, WALK }; 

struct Player {
    // ... (Existing variables) ...
    
    // 2. Variable to hold the current state
    PlayerState currentState; 

    // ... (Existing function declarations) ...
    void Movement();
};

#endif //PLAYER_H
```
