The goal is to make the player's animation switch dynamically between IDLE (when stopped) and WALK (when moving), using the movement logic you already built. This is done by implementing a simple State machine.

1. Identify Needed Changes
	To implement this, we need to make changes in three files:
	1. `player.h`: Define the `enum` for the states and a state variable
	2. `player.cpp`: Update the `Movement` function to change the state based on input
	3. `main.cpp`: Choose the correct `SheetAnim` instance (`idle` or `walk`) for logic and drawing
