The `Player::Movement()` function is the perfect place to check input and set the state. If the accumulated `playerDirection` is non-zero, the player is walking 

`player.cpp` (Movement -> State Logic)
	Modify the `Player::Movement()` function to set `currentState`.

```c++
// player.cpp

void Player::Movement() {
    playerDirection = {0.0f, 0.0f};
    
    // ... (Input checks for KEY_W, KEY_S, KEY_A, KEY_D) ...

    if (playerDirection.x != 0 || playerDirection.y != 0) {
        playerDirection = Vector2Normalize(playerDirection);
        currentState = WALK; // Player is moving: WALK state
    } else {
        currentState = IDLE; // Player is stationary: IDLE state
    }

    // Position update remains the same
    playerPosition.x += playerDirection.x * playerSpeed * GetFrameTime();
    playerPosition.y += playerDirection.y * playerSpeed * GetFrameTime();

    // ... (playerRect updates remain the same) ...
}
```
