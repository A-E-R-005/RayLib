Ensuring your camera only shows the defined game world and doesnt pan out to reveal the area outside.

```c++
float targetX = Clamp(player.playerPosition.x, halfScreenWidth, WORLD_WIDTH - halfScreenWidth);
float targetY = Clamp(player.playerPosition.y, halfScreenHeight, WORLD_HEIGHT - halfScreenHeight);
gameCamera.target = (Vector2){targetX, targetY};
```
This is correct but for clamping the camera's target position so the camera stays centered on the player, but it will still show the edges of the world when the player is near them.

The key to fixing this is inderstanding that the camera's target must be clamped based on where the camera's viewable area (the screen) hits the world edge

The `gameCamera.target` is the point in the world that raylib tries to place in the center of the screen

1. Determning the Camera's Limits
	To stop the camera from showing anything outside the boundary, you need to calculate the minimum and maximum position the camera's center (target) can be

|**Limit**|**Calculation**|
|---|---|
|**Minimum Target X ($T_{min\_x}$)**|The camera's center cannot go further left than the **left world edge** ($0$) plus half the screen width.|
|**Maximum Target X ($T_{max\_x}$)**|The camera's center cannot go further right than the **right world edge** ($W=1100$) minus half the screen width.|

$Where:$
W = WORLD_WIDTH
H = WORLD_HEIGHT
$S_w$ = halfScreenWidth
$S_h$ = halfScreenHeight

$Tminx$ = 0 + $S_w$ 
$Tmaxx$ = W - $S_w$

```c++
// In main.cpp
// 1. Calculate the minimum target (left/top)
float minCameraX = halfScreenWidth;
float minCameraY = halfScreenHeight;

// 2. Calculate the maximum target (right/bottom)
float maxCameraX = WORLD_WIDTH - halfScreenWidth; // 1100 - halfScreenWidth
float maxCameraY = WORLD_HEIGHT - halfScreenHeight; // 1100 - halfScreenHeight

// 3. Clamp the player's position to these camera limits
float targetX = Clamp(player.playerPosition.x, minCameraX, maxCameraX);
float targetY = Clamp(player.playerPosition.y, minCameraY, maxCameraY);

gameCamera.target = (Vector2){targetX, targetY};
```
