1. Redefine Speed - Your speed should now be in pixels per second (e.g., 240 pixels per second), not pixels per frame
2. Modify Movement Calculation: Multiply the direction vector by the new speed AND by $\Delta t$ 

```
// Redefine Speed (e.g., 240 pixels per second)
const float playerSpeed = 240.0f; 

// Inside the Update phase:
playerPosition.x += playerDirection.x * playerSpeed * GetFrameTime();
playerPosition.y += playerDirection.y * playerSpeed * GetFrameTime();
```

Now, if the frame rate drops, $\Delta t$ increases (because more time passed between frames), compensating for the lower FPS and keeping the movement speed constant.
