Currently, my player moves by `4.0f` pixels every single frame, controlled by line:

`playerPosition.x += playerDirection.x * playerSpeed; // playerSpeed = 4.0f`

🛑The Problem with Fixed Frame Movement:
- If you run your game on a powerful computer, it might consistently hit the 60 FPS target. The player moves: 4 pixels/frame x 60 frames/second = 240 pixels/second
- However, if the player's computer slows down due to background tasks or a busy CPU, the game might only run at 30 FPS. The player movement then becomes: 4 pixels/frame x 30 frames/second = 120 pixels/second

The result: The games run at different speeds on different computers

✅The Solution: Delta Time ($\Delta t$)
- Delta time $\Delta t$ is the amount of time (usually in seconds) that has passed since the last frame
- Instead of moving a fixed number of pixels per frame, we calculate movement based on pixels per second
- $Movement = Speed \times \Delta t$

In Raylib, the function to get this value is:

| **Function**   | **Signature** | **Explanation**                                                                                       |
| -------------- | ------------- | ----------------------------------------------------------------------------------------------------- |
| `GetFrameTime` | `(void)`      | Returns the time elapsed since the last frame as a **`float`** (in seconds). This is your $\Delta t$. |
