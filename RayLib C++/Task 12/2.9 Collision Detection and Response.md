Collision detection involves determining if two hitboxes overlap. Collision response involves defining what happens when they overlap (e.g., stopping movement, taking damage, picking up an item).

1. Collision Detection
	You have the necessary function in Raylib: `CheckCollisionRecs()`
	This function takes two `Rectangle` structures (your player's 17x13 `playerRect` and the target's `targetRect`) and returns a `bool` (true if they overlap, false otherwise).

2. Collision Response: The challenge 
	- Static Object Interaction (e.g., The Target)
		Since you have a `target` object, you can make the player change color when hitting it, as you've started, but you can also:
		- Trigger and event: Remove the target from the world, increment a score, or play a sound.
		- Change states: Make the target flash or change its animation
	- Obstacle Collision (Stopping Movement)
		If you introduce obstacles (like rocks or walls) that the player cannot pass through, you'll need more advanced logic than simply clamping the player to the world bounds.
			How to implement blocking movement:
				1. Calculate the potential move: Run `player.Movement()` to get the new `playerPosition`
				2. Check for future collision: Calculate the player's future `playerRect` based on the new position
				3. Prevent the move: If the future `playerRect` overlaps with an obstacle's rectangle, revert the `playerPosition` back to its previous (safe) position
