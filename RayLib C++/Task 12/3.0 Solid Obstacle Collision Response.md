The core principle is the "Test and Correct" method. You try to move the player, check if the new position causes an overlap, and if it does, you push the player back to a non-colliding position.

1. Preparation: Define the Obstacle
	First, ensure you have a way to define and store your solid obstacle(s). This is usually a `Rectangle` that won't move.
	Let's assume you've added a solid wall:

```c++
// In main.cpp (Example)
Rectangle wallRect = {200, 200, 150, 50}; // An obstacle at (200, 200) that is 150x50 units
// ...
// In the Draw section:
DrawRectangleRec(wallRect, BROWN); // Visually represent the wall
```

2. The Collision Function: `Player::ResolveCollision()`
	You need a new function in `player.cpp` to handle the collision logic. This function should be called after `player.Movement()` but before `player.Boundaries()`.
	The key is to handle the X and Y movement separately.
	Goal: Prevent Overlap on Both Axes
	If you move diagonally and hit a corner, your code needs to know if the X movement or the Y movement (or both) caused the overlap
