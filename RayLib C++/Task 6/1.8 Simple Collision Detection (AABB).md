The most common and easiest type of collision to implement in 2D is the Axis-Aligned Bounding Box (AABB) collision.
This method checks if two rectangles (boxes) are overlapping.
Since your player is a rectangle, this is the perfect starting point.

1. Defining the Target
	First we need a second object to collide with. Let's create a stationary Target rectangle
	- Define a new Vector2 for the target's position and constants for its size (e.g., a 60x60 green square).

2. Raylib's Collision Function
	Writing the logic to check if two rectangles overlap is tedious. Fortunately, raylib provides a perfect function for AABB collision:

|**Function**|**Signature**|**Explanation**|
|---|---|---|
|`CheckCollisionRecs`|`(Rectangle rec1, Rectangle rec2)`|Returns **`true`** if the two rectangles are overlapping, otherwise `false`.|
3. The `Rectangle` Structure 
	The `CheckCollisionRecs` function doesn't take raw coordinates; it requires raylib's dedicated `Rectangle` structure

|**Structure**|**Fields**|**Explanation**|
|---|---|---|
|`Rectangle`|`float x`, `float y`, `float width`, `float height`|A structure used to define a rectangular area.|
	To use `CheckCollisionRecs`, you must convert your `Vector2` position and width/height variables into a `Rectangle` object for both the player and the target.


4. Collision Logic Flow 
	This logic belongs entirely in the Update phase:
	1. Create Player Rec: Convert the `playerPosition` and dimensions into a `Rectangle` 
	2. Create Target Rec: Convert the `targetPostion` and dimensions into a `Rectangle`
	3. Check Collision: Call `CheckCollisionRecs(playerRec, targetRec)`
	4. React: If the check is `true`, change a state variable (e.g., change the player's colour to show they've collided).
