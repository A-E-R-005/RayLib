In raylib, loading assets (like images) requires careful management.
Assets must be loaded in the Initialization phase and explicitly unloaded in the De-Initialization phase to prevent memory leaks.

1. The `Texture2D` Structure
	The primary data type for images in raylib is `Texture2D`

|**Data Type**|**Description**|
|---|---|
|`Texture2D`|A structure that holds the image data (width, height, ID) loaded into the graphics card's memory (VRAM).|

2.  Loading and Unloading Assets 
	These functions must be placed outside the main `while` loop
	- Initialization (Load)
		Use `LoadTexture` to read an image file (PNG, JPG, etc.) from your hard drive and upload it to the GPU memory.
	- De-Initialization (Unload)
		When the game ends, you must free the GPU memory used by the texture

| **Function**    | **Signature**            | **Explanation**                                                                                    |
| --------------- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| `LoadTexture`   | `(const char *fileName)` | Loads a texture from the specified file path. You must store the result in a `Texture2D` variable. |
| `UnloadTexture` | `(Texture2D texture)`    | Unloads the texture from GPU memory. This is essential for clean shutdown                          |

3. Drawing Textures
	Instead of `DrawRectangle`, you use `DrawTextureV` (Vector version) to draw the loaded texture

| **Function**   | **Signature**                                       | **Explanation**                                                                                                              |
| -------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `DrawTextureV` | `(Texture2D texture, Vector2 position, Color tint)` | Draws the entire texture at the specified `Vector2` position, applying an optional `Color` tint (use `WHITE` for no change). |
