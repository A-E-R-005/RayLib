In game development, the position and properties of an object are referred to as its state. We store state using global or class-level variables (outside of main or before the while loop).

- Position: Raylib has a built-in structure called Vector2 to hold 2D coordinates easily

```
//define a structure for 2D vectors
typedef struct Vector2 {
	float x;
	float y;
} Vector2;

//Example usage:
Vector2 playerPosition = {400.0f, 225.0f};
```
- Speed: We often use a single floating-point number (float) to define the movement speed
