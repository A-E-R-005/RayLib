To make an object move based on input, you check the input and then modify the object's position variable in the Update phase.

```
// Inside the while loop, before BeginDrawing()
// Update phase:
if (IsKeyDown(KEY_RIGHT))
{
	//Increase the X-coordinate to move right
	playerPosition.x += playerSpeed;
}
```

```
// Inside BeginDrawing()
// Draw phase:
DrawRectangle(playerPosition.x, playerPosition.y, 50, 50, BLUE);
```
