Input is handled in the Update section of the game loop
RayLib provides simple functions to check the state of the keyboard:

IsKeyDown(int key)
IsKeyPressed(int key)

|**Function**|**Signature**|**Explanation**|
|---|---|---|
|`IsKeyDown`|`(int key)`|Returns **`true`** if the specified key is currently being held down. This is ideal for continuous movement.|
|`IsKeyPressed`|`(int key)`|Returns **`true`** only once when the key is first pressed. Ideal for single actions like jumping or shooting.|
|`KEY_RIGHT`, `KEY_W`, etc.|`int` constant|Built-in constants for keyboard keys.|
