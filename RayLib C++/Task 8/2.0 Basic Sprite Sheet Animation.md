Animation in 2D games is the process of rapidly displaying different parts of a single image (the sprite sheet) to create the illusion of motion

1. The Sprite Sheet Layout
	My `Soldier-Idle.png` is a sprite sheet - a single image containing multiple frames arranged horizontally. To animate, we need to know:
	- Frame Dimensions: The width and height of a single frame (e.g., if the sheet is 400x50 and has 8 frames, each frame is 50x50)
	- Current Frame: Which frame number (0, 1, 2, etc.) we are currently displaying 

2. The `Rectangle` for Clipping
	The key to animation is drawing only a portion of the large sprite sheet. We use a `Rectangle` to define this source area on the texture 

|**Variable**|**Usage**|
|---|---|
|`sourceRec`|Defines **WHAT** part of the texture image to draw (the current frame).|
|`destRec`|Defines **WHERE** and **HOW BIG** the texture should be drawn on the screen.|

3. Essential New Variables (The Animation State)
	You need new variables to manage the animation cycle:

|**Variable**|**Data Type**|**Purpose**|
|---|---|---|
|`frameWidth`|`float`|Width of a single frame.|
|`frameHeight`|`float`|Height of a single frame.|
|`frameIndex`|`int`|The index of the frame to display (0 to 7).|
|`frameTime`|`float`|Timer to control when to advance to the next frame.|
|`updateTime`|`float`|How long (in seconds) to display each frame (e.g., `1.0f/12.0f` for 12 FPS).|

4. Animation Logic (The Update Phase)
	The animation logic $\Delta t$ (Lesson 5) to control the speed of the animation, regardless of the game's FPS

```c++
// Inside the Update loop:
frameTime += GetFrameTime(); // Add elapsed time since last frame

if (frameTime >= updateTime)
{
    frameTime = 0.0f; // Reset the timer
    
    // Move to the next frame
    frameIndex++;
    
    // Loop back to the first frame if we reach the end
    if (frameIndex > totalFrames) { // Replace totalFrames with the count of frames (e.g., 7)
        frameIndex = 0;
    }
}
```

5. Drawing the Animated Frame
	We use a special function, `DrawTextureRec`, which draws only the area defined by the `sourceRec` onto the area defined by the `destRec`.

|**Function**|**Signature**|**Explanation**|
|---|---|---|
|`DrawTextureRec`|`(Texture2D texture, Rectangle source, Vector2 position, Color tint)`|Draws the area defined by `source` from the `texture` onto the screen at the given `position`.|
The `sourceRec` is calculated based on the current `frameIndex`:

$SourceRec.x = FrameIndex \times Frame Width$
